# Autonomous AI Robot

## Overview
An autonomous AI robot capable of:
- Voice interaction
- Obstacle detection
- Autonomous navigation
- Object recognition

## Technologies Used
- Python
- Vosk Speech Recognition
- OpenCV
- Raspberry Pi
- ESP32

## Features
- Voice commands
- Real-time obstacle avoidance
- Autonomous movement
- Sensor integration

## Hardware Components
- Ultrasonic Sensors
- Camera Module
- Motor Driver
- DC Motors
